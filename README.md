# Dial for Android

**Download:** [Dial.apk](https://github.com/Joed1986/dial-android/releases/latest/download/Dial.apk)

1. Open the link above on your Android phone, tablet, Google TV or Fire TV (on a TV, use the Downloader app and type the link).
2. When it finishes downloading, open it and choose **Install**.
3. The first time, Android asks to allow installs from that app: tap **Settings**, switch on **Allow from this source**, then go back.
4. If Play Protect says the developer is unknown, tap **More details → Install anyway**.

Dial finds your Channels DVR on the network by itself. It checks this page for updates and offers to install them (Settings → App updates).
